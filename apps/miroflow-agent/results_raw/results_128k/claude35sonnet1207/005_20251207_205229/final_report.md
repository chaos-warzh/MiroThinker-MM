## 3. 关键技术解析

### 3.1 学习动态

学习动态描述了模型在学习新样本时，其预测如何变化。在本研究中，学习动态被定义为"模型参数θ的变化如何影响相应的fθ变化"，即∆θ和∆fθ之间的关系 [pdf.pdf, Page 2]。

关键公式：
∆θ ≜ θt+1 - θt = -η · ∇L(fθ(xu), yu)
∆f(xo) ≜ fθt+1(xo) - fθt(xo)

这里，η是学习率，L是损失函数，xu是输入样本，yu是目标输出 [pdf.pdf, Page 2]。

### 3.2 微调技术

1. 监督微调（SFT）：
   SFT的损失函数是给定提示xu条件下，完成y+u的负对数似然（NLL）：
   LSFT(xu, y+u) = -Σ log π(y = y+l | y+<l, xu)
   [pdf.pdf, Page 4]

2. 直接偏好优化（DPO）：
   DPO的损失函数为：
   LDPO(θ) = -E(xu,y+u,y-u)~D [log σ(β log(πθt(y+u|χ+u) / πref(y+u|χ+u)) - β log(πθt(y-u|χ-u) / πref(y-u|χ-u)))]
   其中，y+u和y-u分别是偏好和非偏好响应，πref是参考模型（通常是SFT的结果）[pdf.pdf, Page 5]。

### 3.3 "挤压效应"

"挤压效应"是在使用具有Softmax输出层的模型的负梯度时观察到的现象。主要特征包括：

1. y-u的置信度会降低。
2. 减少的概率质量主要"挤压"到更新前最有信心的输出上。
3. 高πθt的维度倾向于增加，低πθt的维度倾向于减少。
4. 如果πθt集中在少数维度上，挤压效果更明显。
5. 较小的πθt(y-u)会加剧挤压效应。

[pdf.pdf, Page 6]

这一效应解释了为什么在离线DPO中，几乎所有响应的置信度都会降低，而模型可能会重复生成简单的短语 [pdf.pdf, Page 6-7]。

### 3.4 Transformer架构

虽然论文没有直接讨论Transformer架构，但它是现代LLM的基础。在微调过程中，Transformer的自注意力机制和前馈网络层的参数都会被更新。学习动态分析揭示了这些更新如何影响模型在不同输入上的预测 [long_context: "Transformer Architecture in LLMs", chunk 3]。

Transformer的关键组件包括：

1. 多头自注意力机制：允许模型关注输入序列的不同部分。
2. 位置编码：为模型提供序列中token位置的信息。
3. 前馈网络：在每个Transformer层中处理注意力机制的输出。
4. 层归一化：有助于训练的稳定性。

在微调过程中，这些组件的参数会根据特定任务进行调整，从而影响模型的学习动态 [long_context: "Finetuning Transformers", chunk 2]。
